# Islamic-Banking-Performance-Dashboard-Power-BI-
A comprehensive financial analytics dashboard tailored for Islamic banking institutions, enabling executives to monitor performance and compare across peer banks

## Overview
This project delivers a comprehensive financial analytics dashboard tailored for Islamic banking institutions, enabling executives to monitor performance and compare across peer banks.

## Objective
To provide a centralized dashboard for:
- Financial performance tracking
- Cross-bank comparison
- Executive-level decision-making

## Tools Used
- Power BI
- Power Query (Data Transformation)
- DAX (Measures & KPIs)
- SQL Server

## Features
- KPI Cards (Revenue, Profit, Assets)
- Bank comparison (Jaiz, Lotus, Taj, etc.)
- Gauge charts for performance tracking
- Radar chart for multi-bank comparison
- Trend analysis over time

## Key Insights
- Identified top-performing banks across key metrics
- Highlighted performance gaps between competitors
- Enabled quick executive-level insights

## Business Impact
- Supports strategic decision-making
- Enhances financial transparency
- Improves stakeholder reporting
